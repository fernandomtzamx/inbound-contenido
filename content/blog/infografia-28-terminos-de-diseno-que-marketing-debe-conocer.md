## El proceso
- **Wireframe:** diseño básico que aún no tiene elementos de diseño.
- **Composición:** el siguiente paso; cómo se verá el diseño terminado.
- **Prototipo:** versión que da una idea cercana del producto final.

## Las letras
- **Leading (interlineado):** espacio vertical entre líneas de texto.
- **Kerning:** ajuste del espacio entre caracteres.
- **Tipografía:** el arte de acomodar el texto de forma atractiva.
- **Fuente:** colección de caracteres, signos, números y símbolos.

## Elementos visuales
- **Bleed (sangrado):** el diseño se extiende más allá del límite de la página para que no queden márgenes blancos al cortar.
- **Grid (retícula):** guía para alinear elementos y dar consistencia.
- **Degradado:** transición de un color a otro, o de opaco a transparente.
- **Espacio en blanco:** área vacía que ayuda a enfocar otros elementos.
- **Padding:** espacio entre un borde y el objeto dentro de él.
- **Margen:** espacio entre el borde y el objeto fuera de él.

## La web
- **Abajo del doblez:** la parte de la página que se ve solo al desplazarse.
- **Responsive:** diseño que se adapta a distintos tamaños de pantalla.
- **Resolución:** puntos por pulgada; la infografía cita 72 dpi para web y 300 o más para impresión.
- **Fuentes seguras en la web:** como Arial, Georgia o Times.
- **Colores web:** se representan con códigos hexadecimales de 6 dígitos.

## Acrónimos
- **CMYK:** cian, magenta, amarillo y negro; para impresión.
- **RGB:** rojo, verde y azul; para pantallas.
- **DPI / PPI:** puntos o píxeles por pulgada.
- **UI:** la interfaz del usuario.
- **UX:** la experiencia del usuario.

## Archivos
- **JPG:** ideal para fotos con degradados.
- **GIF:** estático o animado, común en web.
- **PSD:** archivo de Adobe Photoshop.
- **PDF:** ideal para enviar materiales a imprimir.
- **PNG:** admite transparencia y es útil en web.

## Dos actualizaciones

Hoy las webs usan fuentes web (como Google Fonts), así que ya no dependes de Arial o Georgia, y formatos como WebP y SVG pesan menos y cargan más rápido. ## Preguntas frecuentes

### ¿Qué diferencia hay entre CMYK y RGB?

CMYK se usa para impresión (cian, magenta, amarillo y negro); RGB, para pantallas (rojo, verde y azul).

### ¿Qué es el kerning?

El ajuste del espacio entre caracteres de una palabra para que se vea equilibrada.

### ¿Qué diferencia hay entre UI y UX?

UI es la interfaz, lo que el usuario ve y toca; UX es la experiencia completa al usar un producto o sitio.
